# HashCode Brand Architecture

## 1. Brand hierarchy

HashCode uses a **branded house** architecture.

```
HASHCODE
│
├── COMMUNITY
├── ACADEMY
├── SECURITY
└── LABS
│
└── REBOOT (campaign / transformation identity)
```

The official HashCode logo remains the primary visual signature. The poles are not independent brands and must not create competing logos.

## 2. The four poles

### HashCode Community
**Purpose:** connect people, conversations, events and collaboration.

- Accent: `#60A5FA`
- Visual code: connection / network nodes
- Keywords: Connect · Share · Build Together
- Primary use: community announcements, meetups, onboarding and ecosystem activity

### HashCode Academy
**Purpose:** structured learning, workshops and skill development.

- Accent: `#A78BFA`
- Visual code: learning path / stacked blocks
- Keywords: Learn · Practice · Master
- Primary use: courses, workshops, learning tracks and educational content

### HashCode Security
**Purpose:** cybersecurity education, ethical security practice and intelligence.

- Accent: `#F97316`
- Visual code: shield / signal
- Keywords: Understand · Defend · Investigate
- Primary use: security sessions, CTF, OSINT and cyber education

### HashCode Labs
**Purpose:** experimentation, prototypes, research and technical projects.

- Accent: `#22C55E`
- Visual code: experiment / terminal / nodes
- Keywords: Explore · Experiment · Ship
- Primary use: prototypes, demos, research and engineering projects

## 3. Core brand rule

The HashCode lime remains the dominant brand color:

- HashCode Lime: `#C5F441`
- Background: `#050607`
- Primary text: `#F5F7FA`

Pole accents are secondary. They identify context; they do not replace HashCode.

## 4. Lockup system

Use typography-based descriptors rather than creating four new logos.

```
HASHCODE
COMMUNITY

HASHCODE
ACADEMY

HASHCODE
SECURITY

HASHCODE
LABS
```

The official HashCode logo is used on major covers and institutional moments. The pole name can appear as a contextual signature.

## 5. HashCode Reboot

HashCode Reboot is a campaign / transformation identity, not a fifth permanent pole.

Use it for:

- community reconstruction
- activation campaigns
- relaunch announcements
- transformation milestones

Do not use it as the default identity of every HashCode presentation.
