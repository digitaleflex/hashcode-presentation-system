# HashCode Workshop System

Every workshop presentation should be built around participation, not passive slides.

## Standard rhythm
- Explain
- Demonstrate
- Let participants practice
- Debrief
- Produce a concrete next action

## Core components
- `HCWorkshopTimer`
- `HCChallenge`
- `HCExercise`
- `HCPresenterCue`

## Presenter notes convention

Use Slidev speaker notes for private animation guidance and facilitation instructions.

Recommended note structure:

- **TIME** — planned duration
- **SAY** — key message
- **ASK** — question for participants
- **DEMO** — action to perform
- **TRANSITION** — bridge to the next slide

## Quality gate
A workshop is not complete unless it has:
1. a learning objective
2. an interactive moment
3. a practical exercise
4. an expected deliverable
5. a debrief
6. a next action
