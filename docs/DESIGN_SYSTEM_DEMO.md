# Design System Demo

## Purpose
The Layout Showcase is the visual validation bench for the HashCode Presentation System.

## Location
`slides/design-system/showcase.md`

## Layouts covered
1. hash-hero
2. hash-comparison
3. hash-timeline
4. hash-diagram
5. hash-code
6. hash-stats
7. hash-quote
8. hash-workshop

## Validation criteria
- no text overflow
- readable typography
- correct contrast
- consistent spacing
- approved HashCode branding
- clear visual hierarchy
- one dominant idea per slide

A successful technical build does not equal visual approval.
