# HashCode Pole Visual System

## Decision

HashCode will **not** create four independent logos.

Instead, the system uses:

1. One official HashCode logo.
2. Four contextual pole identities.
3. One campaign identity: HashCode Reboot.

## Visual grammar

Every pole shares:

- the official HashCode logo
- dark background
- HashCode Lime as the master color
- the same typography
- the same spacing and layout principles

Each pole adds only one contextual accent.

## Slide usage

### Cover slide
Use the official HashCode logo + pole descriptor.

Example:

```
[HASHCODE LOGO]

ACADEMY
AI & PRODUCTIVITY
Workshop Series
```

### Section slide
Use the pole label and its accent line.

### Footer
Use a small HashCode mark. The pole accent can identify the current track.

## Do not

- redesign the HashCode symbol for each pole
- create unrelated typography
- replace the lime with the pole accent everywhere
- use HashCode Reboot as the default signature
