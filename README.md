# ⚡ HashCode Presentation System

Reusable presentation infrastructure for HashCode workshops, training and technical sessions.

## Brand architecture

The system uses a **branded house** model:

- HashCode Community
- HashCode Academy
- HashCode Security
- HashCode Labs

All poles share the HashCode master identity. Pole accents provide context without creating four competing logos.

HashCode Reboot remains a campaign / transformation identity.

## Pole themes

- `HCCommunityTheme`
- `HCAcademyTheme`
- `HCSecurityTheme`
- `HCLabsTheme`
- `HCTheme` — generic contextual wrapper

See `docs/BRAND_ARCHITECTURE.md`, `docs/POLE_VISUAL_SYSTEM.md` and `docs/LAYOUT_POLE_MATRIX.md`.

## Design principles

- Dark-first interface
- HashCode lime: `#C5F441`
- Strong typography and generous whitespace
- One dominant idea per slide
- Reusable components instead of copy/paste design
- Layout controls structure; theme controls context

## Core layouts

- `hash-cover`
- `hash-section`
- `hash-content`
- `hash-workshop`
