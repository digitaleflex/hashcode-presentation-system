# HashCode Slidev Theme

This directory is the internal foundation for the future distributable `slidev-theme-hashcode`.

## Theme responsibilities
- global HashCode visual tokens
- default typography and backgrounds
- brand-aware layouts
- pole context
- reusable workshop components

The project remains an internal presentation framework during the pilot phase. It should become a standalone npm Slidev theme only after at least three real HashCode presentations validate the API and design decisions.
